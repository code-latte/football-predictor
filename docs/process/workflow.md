# Workflow

This project follows **Kanban with XP practices**.

## Board Columns
- **New** → Raw backlog, no WIP limit.  
- **Ready** → Refined, ready to be picked. Limit: ~2–3× dev team size.  
- **In Progress** → Work in development. Limit: 1 item per developer/pair.  
- **Ready for Testing** → Finished dev, pending review/tests. Limit: equal or less than In Progress.  
- **Done** → Completed, no limit.

## WIP Limits
- Encourage flow, avoid bottlenecks.  
- If a column hits the limit, stop starting new tasks and focus on finishing.  

## Swimlanes
- Used to group cards by **epic** (Predictions, Fixtures, Scoring, Notifications).  
- Alternative swimlanes: Bugfix, Technical debt, Priority.  

## XP Practices
- Pair programming encouraged.  
- "Stop starting, start finishing".  
- Continuous integration: main is always deployable.
