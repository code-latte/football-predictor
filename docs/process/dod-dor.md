# Definition of Ready & Definition of Done

## Definition of Ready (DoR)
A user story is considered **ready** if:
- It has a clear description and acceptance criteria.  
- It is small enough to be completed within a few days.  
- Dependencies are identified.  
- Acceptance criteria are testable.  

## Definition of Done (DoD)
A user story is **done** when:
- Code is reviewed (pair programming or PR).  
- Unit tests are implemented and passing.  
- Integration/contract tests are updated.  
- Logging and metrics are in place.  
- Documentation (if relevant) is updated.  
- The feature is deployed to main and is production-ready.
