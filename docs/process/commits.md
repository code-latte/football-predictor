# Conventional Commits

We follow the **Conventional Commits** standard (optionally with Gitmoji).

## Format
```
<type>(optional scope): <description>
```

## Types
- **feat**: a new feature.  
- **fix**: a bug fix.  
- **refactor**: code change without new feature or fix.  
- **test**: add or update tests.  
- **docs**: documentation only changes.  
- **chore**: other tasks (build, tooling, CI/CD).

## Examples
✅ `feat: add endpoint to submit predictions`  
✅ `fix: correct score calculation when match goes to penalties`  
✅ `:sparkles: feat: implement league creation`  
❌ `update stuff`
